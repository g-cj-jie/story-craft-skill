# 世界观构建方法论

本文档汇集世界观搭建、规则校验、地理历史设计、数值系统设计的具体操作方法和模板。与 `prep-dimensions.md`（维度清单）互补——后者定义"要做什么"，本文档定义"怎么做"。

---

## 一、核心锚点设计法

每个世界必须确定3个"独特锚点"——与同类作品最不同的核心设定。锚点必须满足：
1. 一句话能说清楚
2. 能持续产出剧情冲突
3. 与主角金手指有直接关联

**示例（暗黑×魔兽穿越文）**：
- 锚点1：暗黑2死灵法师体系完整穿越到魔兽世界——两个体系互不兼容
- 锚点2：主角只有一条命——没有灵魂医者复活，受伤就是真的受伤
- 锚点3：魔兽地图放大50-500倍——中世纪真实尺度，行军需要数周

**边界条件四问**（每个核心设定必须回答）：
| 问题 | 说明 |
|------|------|
| 上限 | 这个设定的最强形态是什么？ |
| 下限 | 这个设定的最弱形态是什么？ |
| 边界 | 什么情况下这个设定会失效？ |
| 代价 | 使用这个设定需要付出什么？ |

**未解问题清单模板**（设定中故意留白，给剧情留空间，最多追踪10条）：
| 未解问题 | 预留原因 | 计划揭示章节 | 揭示方式 |
|---------|---------|:----------:|---------|
| ... | ... | ... | ... |

## 二、连锁推演法

### 2.1 基本方法

对每个核心设定做"如果X存在，那么必然Y"的推演，至少推3层：

**示例：主角可以无限召唤骷髅**
- 第1层（直接后果）：主角的战斗力随骷髅数量线性增长
- 第2层（社会后果）：任何一个势力都会想控制/消灭主角——他是移动的军队
- 第3层（经济后果）：如果法力能轻易维持大量骷髅→死灵法师可以取代人类军队→世界经济/政治体系会完全不同
- 结论：必须限制骷髅数量，否则整个世界的社会结构都要改写

### 2.2 五维推演检查清单

每个核心设定至少推演以下5条中的3条：
1. **经济影响**：这个设定会影响什么经济活动？
2. **军事影响**：这个设定会改变战争方式吗？
3. **社会影响**：这个设定会导致什么社会阶层变化？
4. **心理影响**：普通人知道这个设定后会有什么反应？
5. **生态影响**：这个设定会改变自然/环境/生态链吗？

### 2.3 七层地理连锁推演示例

> 设定：大陆中部有一条南北走向的巨大山脉
> → 连锁1：山脉两侧的气候不同（迎风面多雨/背风面干旱）
> → 连锁2：山脉两侧的农业方式不同（雨林 vs 旱地农业）
> → 连锁3：山脉两侧的饮食文化不同（谷物为主 vs 薯类为主）
> → 连锁4：山脉是天然的军事屏障→两侧从未被同一个政权统一过
> → 连锁5：山脉两侧的语言700年前是同一种语言→现在互相理解只有40%
> → 连锁6：两侧的"他们"是"我们"的天然假想敌→两侧的文化中都包含了对"山那边的人"的刻板印象
> → 连锁7：主角从山的一侧到另一侧——不仅是地理移动，是社会文化重置

## 三、现实参照匹配法

对每一项重大设定，找出至少1个现实世界中的参照：

| 设定 | 现实参照 | 参照的规律 | 对本作的启示 |
|------|---------|----------|------------|
| 死灵法术被视为禁忌 | 中世纪欧洲的"黑魔法"恐慌 | 社会对未知力量的恐惧→排挤→迫害 | 主角面对的不只是敌人，还有"自己人"的恐惧 |
| 骷髅军团作为战力 | 历史上的佣兵团/私兵制度 | 养兵需要后勤/资金/纪律 | 骷髅不需要吃饭但维护需要法力/材料，数量有上限 |
| 穿越者隐藏身份 | 现实中的卧底/间谍生存策略 | 身份暴露=死亡，需要多层伪装 | 主角每一次暴露能力都是高风险决策 |

**规则**：找不到现实参照的设定→可能是"纯空想"设定→需要额外注意逻辑自洽。

## 四、隐性矛盾检测

以下5类矛盾是写手最容易犯的，必须主动检测：

| 矛盾类型 | 检测方法 | 示例 |
|---------|---------|------|
| **规模矛盾** | 设定A的规模与设定B的规模不兼容 | "65具骷髅=一支小军队" vs "要塞守军只有50人"——为什么还需要守军？ |
| **时间矛盾** | 事件C的发生时间与旅行/成长时间不兼容 | "3天内穿越西部荒野" vs "步行需要5-7天" |
| **信息矛盾** | 角色知道的信息与他获取信息的渠道不匹配 | 主角在第5章知道暴风城高层内斗——他从哪知道的？ |
| **动机矛盾** | 角色的行为与他的利益/性格/处境不一致 | 一向谨慎的主角突然涉险救人——动机是什么？ |
| **稀缺性矛盾** | 某事物被描述为"稀有"但频繁出现 | "上古神器"但每10章出现一把→不再稀有 |

## 五、反套路素材库

### 战斗反套路
- 反派不是"轻视主角"而是"过度重视"——直接派最强战力碾压
- Boss战不是"双方全力对轰"——一方可能目标不是打赢而是拖延/偷取/掩护撤退
- "以弱胜强"不靠暴种——靠地形/陷阱/信息差/第三方介入

### 身份反套路
- 穿越者隐藏身份不是"没人怀疑"——而是"已经有人怀疑了，只是没找到证据"
- 暴露能力不是"全场震惊然后接受"——更可能是"恐惧→排挤→追捕"
- 贵族不是"要么好人要么坏人"——是好是坏取决于主角站在哪一边

### 日常反套路
- 冒险者公会不是"温暖的大家庭"——是情报交易市场，人人都有自己的算盘
- 升阶不是"等级到了自动升"——可能需要稀有材料/特定条件/势力背书
- 队友不是"一见如故"——信任是逐步建立的，中间会有试探和反复

### 反套路触发条件

当写手写出以下套路时，主动给出反套路建议：
- 反派因为"轻敌"而被打败
- 主角因为"愤怒"而爆发出远超等级的力量
- 所有人因为主角"展现实力"而对他改观
- 消息传播速度快到不自然（"整个城市都知道了"）

## 六、地理设计方法

### 6.1 地图缩放与旅行速度

| 地图类型 | 缩放倍数 | 旅行方式 | 参考速度 | 含义 |
|---------|:------:|---------|:------:|------|
| 区域内部 | 50x | 步行 | 30km/天 | 小区域东西穿越约7-10天 |
| 跨区域 | 100x | 骑马/马车 | 50km/天 | 主城到卫星镇约2-3天 |
| 跨大陆 | 500x | 船/飞艇 | 不定 | 大陆南北穿越约3-6个月 |

**旅行时间使用规则**：
- 有战斗/遭遇→实际旅行时间是标准时间的1.5-2倍
- 有伤员/辎重→按马车速度计算
- 传送门/飞行点→必须提前确认该地点有该设施（大部分地区没有）

### 6.2 场景地理辞典模板

每个重要场景必须包含以下字段：

```
【场景名称】
【地理位置】在哪个区域/大陆的哪个位置
【地形地貌】山地/平原/森林/沼泽/沙漠——具体特征（不是"一片森林"而是"橡树为主的老林，树冠遮天，地面蕨类密集"）
【气候条件】温度范围/降水/季节特征/极端天气
【气候对日常的影响】穿/吃/住/行的具体约束
【资源特产】矿产/药材/怪物种类
【势力归属+控制半径】权力中心→控制范围（步行?天内的区域=有效控制范围，之外=名义控制或独立）
【交通状况】到邻近场景的距离+旅行时间+道路质量+危险等级
【语言/方言】该区域使用的语言/方言+与邻近方言的互通度
【识字率估算】基于政体+城/镇/村级别的估算
【防御/战略价值】为什么这里重要？控制这里意味着控制什么？
【剧情可用性】这个场景适合什么类型的剧情？（埋伏/大规模战斗/角色对话/探索发现）
【文化特征】至少1条该区域特有的风俗/饮食/节日
```

### 6.3 地理一致性检查

每一章涉及位置移动时检查：
1. 起点→终点的距离与旅行时间是否匹配？
2. 中途经过的地点是否有提及？（不能从A直接跳到C而B在中间被忽略了）
3. 旅行时间与章节之间的时间线是否一致？（第10章出发第11章到达，但中间只有1天是不够走完5天的路）
4. 是否有"地理瞬移"？（角色在不需要的时间出现在不可能的地点）

### 6.4 旅行时间速查表格式

```
起点 → 终点 → 距离 → 步行时间 → 骑马时间 → 商队时间 → 紧急行军时间 → 途经危险区 → 备注
```

## 七、地形-文化-语言交互规则

### 7.1 语言与地理的因果链

| 地理特征 | 对语言的影响 | 示例 |
|---------|------------|------|
| 山脉 | 方言边界——两侧语言在500年后互相理解度<60% | "山南口音"和"山北口音"实际上是两种语言 |
| 大河 | 语言通道——沿河两岸趋向语言统一（贸易交流频繁） | 沿河300公里的方言差异<山区30公里的差异 |
| 海洋 | 跨海传播——港口城市语言混杂，内陆保持纯净 | 港口城市有大量外来借词，内陆语言更保守 |
| 沙漠 | 语言孤岛——绿洲聚落保存古语特征（隔离效应） | 沙漠绿洲的"古语存活"现象 |
| 沼泽/密林 | 区域隔离——树冠/沼泽阻碍交流，方言碎片化 | 密林区每个村庄的方言可能无法与隔壁村交流 |

### 7.2 语言边界的渐变规则

- 语言边界不是一条线——是"渐变带"（宽度约30-50公里）
- 渐变带内的居民通常是双语者
- 贸易中心的语言边界更模糊（混杂语）、偏远区域更清晰
- 征服/殖民会在短期内创造突兀的语言孤岛——但在300年后要么同化要么消亡

### 7.3 气候带与文化特征的对应

| 气候带 | 农业方式 | 饮食习惯 | 建筑特点 | 社会节奏 |
|-------|---------|---------|---------|---------|
| 热带雨林 | 无需储存食物（全年可耕种） | 蔬果为主，发酵食品防腐 | 架空建筑，通风为主 | 慢——不需要规划冬季 |
| 温带（四季分明） | 储粮系统发达 | 谷物+腌制肉类+越冬蔬菜 | 厚墙+斜顶（排雪） | 快——夏天储存、冬天熬过 |
| 干旱草原 | 游牧为主 | 奶+肉+血（牲畜） | 可移动帐篷 | 极快——随水草迁移 |
| 寒带/冰原 | 渔猎采集，极少农业 | 脂肪为主（高热需求） | 半地下（保温） | 季节性——极长冬夜限制活动 |
| 沙漠 | 绿洲农业+贸易 | 干粮+沙漠作物+进口 | 厚墙小窗+地窖 | 极慢——日间不可在户外活动 |

**关键规则：如果角色来自热带雨林社会，他不会"未雨绸缪"——因为他的文化里没有冬天。**

### 7.4 地形对政体类型的影响

| 地形 | 最可能出现的政体 | 原因 |
|------|---------------|------|
| 连片平原 | 中央集权帝国 | 军队可以快速移动→镇压分裂→统一成本低 |
| 破碎山地 | 城邦/部落分立 | 每个山谷=独立防御单位=统一成本极高 |
| 沿海群岛 | 商业联盟/城邦 | 海运连接→不需要陆地统一 |
| 大河三角洲 | 神权/官僚制 | 灌溉需要中央管理→"水=控制" |
| 沙漠绿洲 | 贸易城邦 | 每条商路=一个独立权力中心 |
| 密林区域 | 村落民主/小型部落 | 丛林阻碍征服→大型政权无法有效统治 |

**强制规则**：为每个区域确定地形后→必须推演出至少1种主导政体→再根据政体推演教育/道德。

### 7.5 气候-农业-饮食-节日连锁

```
气候带 → 生长季节长度 → 适合种植的作物 → 食物储存方式 → 饮食文化
                                                            ↓
                                                      节日/仪式
                                                            ↓
                                                      文化认同
```

每个文化聚落至少设计1个"气候驱动"的节日：
- 丰收节（秋季、庆祝储存完成）——谷物区普遍
- 播种节（春季、祈求风调雨顺）——依赖灌溉的农业区
- 雨季祭祀（热带区域——雨季"第一场雨"落下的那一刻）
- 冬幕节（寒带——冬至日，最长的夜晚之后白天开始变长=希望）

## 八、历史年表设计

### 8.1 设计规则

1. 历史不是事件列表而是因果链——每个事件必须有"原因→事件→后果→对现在的影响"
2. 历史年表必须包括：创世神话→上古时代→中古时代→近代→故事开篇前夜
3. 每个时代至少保留1个"未解之谜"——给剧情留素材
4. 历史事件的参与者如果还活着，必须标注"当前状态"

### 8.2 历史年表条目模板

```
【时代】名称+大致年代
【关键事件】事件名 → 发生时间 → 直接原因 → 事件经过（3-5句）→ 直接后果 → 对"现在"的具体影响
【未解之谜】这个时代留下的、在故事开篇时尚未解开的谜团
【遗留人物】这个时代的人物中，哪些还在故事开篇时活着？他们在哪？
```

**关键规则**：历史事件对"现在"的影响必须是具体的——不能写"影响了后来的格局"——要写"导致暴风城与铁炉堡之间至今仍有贸易壁垒"这种写手可以直接使用的东西。

## 九、力量等级体系设计

### 9.1 等级表模板

每个等级段必须包含6个字段：

| 字段 | 说明 | 示例（Lv1-5） |
|------|------|-------------|
| 等级区间 | 本阶段涵盖的等级 | Lv1-5：新手 |
| 核心能力 | 本阶段获得的关键能力 | Lv1-6：每级+1技能点 |
| 战力对标 | 相当于什么水平的敌人 | Lv1≈3个普通民兵 |
| 升级条件 | 从本阶段升到下一阶段需要什么 | Lv1-5：累计击杀X+任务经验 |
| 能力边界 | 本阶段绝对不能做什么 | Lv1-5：不能召唤超过3具骷髅 |
| 突破标志 | 什么事件/能力标志着进入下一阶段 | Lv6：解锁黏土石魔 |

### 9.2 数学规则

- 每级经验需求必须有明确公式——不能"差不多够了就升级"
- 骷髅数量上限 = 基础1 + 技能等级（骷髅复苏每级+1，骷髅支配每级额外+0.5，向下取整）。如有超出→必须明确列出加成来源
- 技能消耗法力必须明确数值——不能"消耗大量法力"

### 9.3 技能树设计铁律

每个技能必须包含：
```
技能名称 → 所属树 → 学习等级 → 法力消耗（精确数值）→ 冷却时间 → 效果描述（可量化）→ 每级提升幅度 → 上限等级 → 与其他技能的联动
```

1. 没有"无限/无敌/无代价"的技能——每个技能必须有至少一个限制
2. 技能效果必须可量化——"大幅提升攻击力"不合格，"攻击力+30%"合格
3. 技能组合必须有明确规则——A技能+B技能能产生什么效果？C技能与D技能互斥？
4. 核心技能（主角招牌技能）的升级路径必须提前规划到满级

### 9.4 战力对标表格式

| 主角等级 | 最大召唤数 | 可单挑的敌人 | 需要队友的敌人 | 绝对打不过的敌人 |
|:-------:|:--------:|------------|-------------|---------------|
| Lv1-3 | 1-3 | 沉沦魔单体 | 沉沦魔群 | 精英怪 |
| Lv4-6 | 4-6 | 普通骷髅兵 | 精英怪 | Boss级 |
| Lv7-12 | 7-10 | 精英怪 | 小型Boss | 统帅级Boss |

## 十、社会系统设计

### 10.1 政体-教育-道德三元关联表

每个势力/聚落必须标注：

| 政体 | 典型识字率 | 教育内容 | 核心道德准则 | 社会流动渠道 |
|------|:--------:|---------|------------|------------|
| 部落制 | <5% | 口传历史+生存技能 | 对氏族的忠诚 | 战功/智慧（长老推举） |
| 封建君主制 | 贵族>80% / 平民10-20% | 贵族：治理+礼仪+军事；平民：无 | 忠于领主+履行义务 | 军功（极罕见的封爵） |
| 神权政体 | 教士>90% / 平民<20% | 宗教经文+教会法 | 虔诚+遵循教义 | 教会内晋升 |
| 财阀/商业城邦 | 商人>70% / 平民30-50% | 算术+法律+商业知识 | 守信+履行契约 | 商业成功 |
| 法师贵族 | 魔法者>95% / 无魔力者<6% | 奥术+魔法理论+魔导 | 追求知识+魔力至上 | 魔法天赋 |
| 共和/议会制 | 有产者>60% / 无产者15-20% | 法律+修辞+基础读写 | 遵守法律+公民责任 | 选举/政治生涯 |

**关键规则1：不要用现代教育观念套奇幻世界。大多数奇幻世界设定中平民识字率应低于30%。**

**关键规则2：角色的道德判断基准由其所在社会的政体决定——不是由现代读者的价值观决定。一个"好"的封建骑士可能完全不觉得农奴制有问题。**

### 10.2 道德基准设计模板

每个势力必填：

```
【势力/文化名称】
【最高道德】什么被视为"至善"？（例：对氏族忠诚/虔诚信仰/履行契约）
【最大禁忌】什么被视为"不可饶恕"？（例：背叛氏族/亵渎神明/违约）
【对"外人"的准则】对本族人和对外族人的标准差异（大/中/小/无差异）
【耻辱的洗刷方式】耻辱可以通过什么方式洗刷？（战功/赎罪/献祭/时间/不可洗刷）
【弱者保护原则】社会如何对待无法自保的人？（氏族赡养/教会救济/家庭责任/自生自灭）
【荣誉vs利益的权重】荣誉与生存冲突时社会期望你选择什么？
```

### 10.3 教育真实化规则

奇幻世界的教育不是"学校系统"：
- 修道院/寺庙 = 主要识字教育场所——但教的是经文而非科学
- 商人家庭教育 = 实用教育——算术、法律、外语——不教文学哲学
- 贵族家庭教育 = 古典教育——古语、历史、纹章学、战术——不教"如何赚钱"
- 法师学院 = 极精英——可能占总人口<0.1%
- 平民儿童 = 劳动技能（农活/手工）+口传民间故事——12岁就是正式劳动力
- **强制规则：不要在奇幻世界中出现"公立小学"——除非是现代或近未来的架空世界。**

### 10.4 法律与执法的真实规模

- 一个2000人的镇子通常只有5-10个全职守卫
- 守卫的主要工作是阻止打架、防火、守夜——不是调查犯罪
- 谋杀调查需要外部派人（首都来的法官/巡回裁判团）——几个月才来一次
- 偏远区域的"法律"= 本地乡绅说了算（习惯法）
- 冒险者公会 = 替代了警察的某些功能——悬赏追捕逃犯
- 监狱极少——关押成本太高。多数惩罚是罚款、鞭刑、流放——不是关起来
- 偏远区域（离城市>3天路程）的法律存在感趋近于零——"天高皇帝远"

### 10.5 文化与力量的交互

- 某些文化中"暗影/死亡力量"是完全不可接受的→使用这类力量的角色在该区域活动受限
- 某些文化视特定力量为"神圣"（如牛头人视萨满为神圣、暗夜精灵视艾露恩力量为神圣）
- 文化对力量的接受度直接决定主角在该区域的行动自由——不是"力量强就能为所欲为"

## 十一、设定质量检查

### 11.1 设定审查五条

每次审批设定变更时检查：
1. **自洽性**：这个设定与已有设定矛盾吗？如果矛盾→否决或修改已有设定
2. **连锁影响**：这个设定会导致什么社会/经济/军事连锁变化？推演3步是否合理？
3. **剧情空间**：这个设定能产出多少章剧情？（至少10章剧情空间才值得加入核心设定）
4. **读者理解成本**：读者需要多少字才能理解这个设定？（超过5000字解释→过于复杂）
5. **独特性**：这个设定在同类作品中常见吗？常见=必须做出差异化

### 11.2 设定质量自检

每个设定模块完成后问自己：
1. 这个设定能给剧情提供至少10章的冲突吗？不能→不值得加入核心设定
2. 一个不了解原作的读者能理解吗？不能→需要简化
3. 写手拿到这个设定能直接写吗？还是需要反复问？需要反复问→没说清楚
4. 这个设定有没有"反着用"的空间？（例：力量体系隔离→敌人可以利用这一点）
5. 有没有任何两个设定互相矛盾？有→立即修正

### 11.3 数值一致性检查清单

**技能数值检查**（每卷大纲完成后）：
- [ ] 主角当前等级与实际技能等级是否匹配？
- [ ] 召唤数量是否在公式允许范围内？（如有超出→列出加成来源）
- [ ] 法力消耗是否有明确数值？（模糊描述=不合格）
- [ ] 本章使用的技能是否已在前文解锁？（不能提前使用未解锁技能）

**经验/升级检查**：
- [ ] 本章的等级是否与经验累计一致？
- [ ] 是否有"越级太快"的问题？（连续3章升一级=太快）
- [ ] 是否有"升级停滞"的问题？（超过10章没升级=需要解释）

**战力一致性检查**：
- [ ] 同等级敌人战力是否一致？（上周的Lv5敌人不能比本周的Lv5敌人弱一倍）
- [ ] 主角是否做到了等级不允许的事情？（越级必须有明确原因：地形/准备/克制/队友）

### 11.4 社会一致性检查清单

- [ ] 每个出场聚落都标注了政体类型？
- [ ] 识字率与政体匹配？（商业城邦中一个平民不识字=合理；修道院中的信徒不识字=不合理）
- [ ] 角色的道德判断与其出身社会的道德基准一致？（一个封建骑士不应该有现代平等观念——除非剧情解释）
- [ ] 法律执行能力与聚落规模匹配？（2000人镇子的守卫数量不影响剧情逻辑）
- [ ] 丧葬习俗与该区域的宗教/灵魂观一致？
- [ ] 不同区域的语言互通度有明确标注？
- [ ] 节日的日期与气候/农业周期合理？（丰收节在秋季——如果在春天则必须有特殊解释）

## 十二、设定输出格式

### 12.1 世界观设定条目

```
【设定模块】名称
【具体内容】明确的、不含糊的描述
【为什么这么设计】至少3步逻辑链
【连锁影响】对其他体系的影响（社会/经济/军事/力量）
【边界与限制】上限/下限/失效条件/使用代价
【剧情空间】这个设定能产生什么类型的剧情冲突
【与其他设定的交叉】与哪些设定有交互，交互规则是什么
```

### 12.2 设定验证报告

```
【设定名称】
【现实参照】真实世界中类似的现象/规律/历史案例
【连锁推演】第1层→第2层→第3层（至少3层）
【潜在矛盾】与哪些已有设定存在隐性矛盾
【风险等级】低/中/高——矛盾爆发后对故事的影响程度
【优化建议】至少1个具体可行的建议
```
