# 资料准备维度详解

## 第一层：通用世界观搭建（8个维度）

### 1. 地理与气候
世界地图/区域划分、主要地形、气候带分布、特殊地理景观。

### 2. 种族与生物
智慧种族（外貌/寿命/天赋/社会地位）、特殊生物/魔兽、特殊植物/药材。

### 3. 语言与文字
通用语体系、方言分布、文字系统、命名规则（人名/地名/物品名风格约束）。

### 4. 政治与权力
国家/城邦/势力列表、政体类型、权力更迭规则、法律核心条款、当前政治格局。

### 5. 经济与物产
货币体系（名称/兑换/购买力）、主要物产与贸易路线、资源稀缺性、阶级财富分布。

### 6. 文化与宗教
主要信仰体系（神系/教义/仪式/节日）、生死观宇宙观、社会习俗、禁忌迷信、艺术形式。

### 7. 科技与交通
科技水平定位、交通工具与速度、通信方式与延迟、武器防具体系。

### 8. 力量体系（如有超自然元素）
力量来源、等级划分及每级特征（模糊描述不可量化）、修炼方式与条件、战力对标、稀有度分布。

### 输出格式
每个维度输出到 `世界观设定/` 下独立文件，含：
- 设定现状描述
- 设定来源（原创/参考XX作品/历史原型）
- 对故事的潜在影响
- 开放问题（待补充项）

## 第二层：原作素材采集

### 采集维度
| 维度 | 内容 |
|------|------|
| 剧情时间轴 | 主线任务/事件按时间排列，标注关键节点和分支 |
| 角色库 | 姓名/称号/种族/阵营/性格标签/人际关系/名台词/结局 |
| 世界地图 | 城镇/区域/秘境/副本的位置关系 |
| 势力分布 | 各组织/阵营的目标、实力、关系网络 |
| 力量/经济体系 | 等级/技能树/装备系统/货币/掉落/交易 |
| 核心机制 | 战斗/养成/社交/任务系统 |
| 玩家生态 | PVP/PVE格局/公会/交易行 |
| 隐藏内容 | 官方伏笔/彩蛋/推测/粉丝理论 |

### 采集原则
- 区分"官方正史"和"玩家推测"，标注来源可靠性
- 区分"必须保留的"和"可以改编的"
- 注意版本差异带来的设定变更
- 按对主线重要程度排序，不全量采集

## 第三层：现实化改编

### 核心改编对照
| 原作概念 | 改编方向 | 原则 |
|---------|---------|------|
| 数值化属性(HP/MP/力量) | 模糊感知（伤势程度/精力充沛度） | 人物不能"看到数字" |
| 等级系统 | 境界/段位，感官体现 | 需近距离接触或战斗判断 |
| 技能冷却/蓝耗 | 体力消耗、精神负荷 | 每次有代价 |
| 背包/仓库 | 实际携带限制或有条件空间装备 | 不能无限存取 |
| 复活/重生 | 穿越者特权或完全去除 | 有代价才有张力 |
| UI/任务面板 | 金手指保留或直觉感知 | 需定义触发条件和限制 |
| NPC固定对话 | 真实人物有独立思维 | 世界"活了" |
| 地图传送 | 空间法术需代价或合理交通 | 距离产生叙事空间 |
| 副本/刷怪 | 秘境/遗迹一次性探索 | 不能反复刷 |
| 掉落表 | 符合生物学的产出 | — |
| 阵营声望条 | 实际势力态度 | 不能量化查看 |

### 改编项输出格式
```markdown
### [改编项名称]
- 原作设定: [游戏中如何表现]
- 改编后: [现实化后的逻辑]
- 改编理由: [为什么这样改]
- 叙事影响: [在故事中如何体现]
- 风险提示: [可能引发的逻辑矛盾及应对]
```

### 金手指设计（穿越者特权）
如有系统/面板/前世记忆等特殊能力：
- 明确列出所有能力及限制条件
- 设计成长曲线：初始→升级→最终形态
- 设定使用代价（寿命/精神力/冷却/代价递增）
- 设计"金手指失效"场景制造危机感
- 金手指不能解决所有问题
