# 编辑工作流

## 概览：三审制 + 终审

```
初稿 → 一审(内容编辑) → 二审(文字编辑) → 三审前半(校对) → 三审后半(连续性编辑) → 终审(主编)
  │         │                    │                  │                    │              │
  │     逻辑/节奏/人设        文字润色           错别字/格式         前后文一致性      发还是不发
  │     打回(B/C/D级)       上报严重偏离         上报严重错误        上报不一致         最终裁决
```

负责写作的模型为写手角色（产出正文），负责审查的模型为编辑角色（审查正文），主编角色做最终裁决。

---

## 一、一审：内容编辑（内容层面）

### 一审检查清单（五层，每章必查）

**第一层——逻辑检查**：
- [ ] 本章事件有因果链吗？（A发生→导致B→引出C。不能"突然就...""莫名其妙就..."）
- [ ] 角色行为有动机支撑吗？（每个决策都能追溯到"为什么这么做"）
- [ ] 有逻辑漏洞吗？（角色知道了不该知道的信息？事件发生顺序不可能？）

**第二层——主线检查**：
- [ ] 读完本章后故事前进了一步吗？（如果删掉这章，主线会受影响吗？）
- [ ] 本章是否在主线轨道上？（没有偏离到无关支线？）
- [ ] 如果有偏离——这个偏离是"更好的方向"还是"迷路"？

**第三层——人设检查**：
- [ ] 所有出场角色行为是否符合人设档案？
- [ ] 角色是否有"为推进剧情而降智/变聪明"的情况？
- [ ] 对话是否"千人一面"？（抽查——遮住名字看台词能分出谁是谁吗）

**第四层——节奏与爽点检查**：
- [ ] 是否符合章纲的情绪标注？（章纲说紧张→本章真的紧张吗？）
- [ ] 爽点在预期位置释放了吗？
- [ ] 有没有"读起来想跳过"的段落？（标注位置+原因）
- [ ] 章末钩子是否有效？（读了最后一段想点下一章吗？）

**第五层——信息量检查**：
- [ ] 本章有新信息吗？（至少1个新信息/新进展）
- [ ] 新信息是太多还是太少？（太多→读者晕；太少→读者觉得水）
- [ ] 信息释放方式是否自然？（不能是"角色突然开始科普"）

### 一审评级标准

| 等级 | 判定标准 | 处理方式 |
|:--:|---------|---------|
| A级 | 全部五层检查通过，有至少1个亮点 | 直接流转给文字编辑（二审） |
| B级 | 通过但局部有小问题，修改 <= 30分钟 | 标注问题→写手修改→编辑确认→流转 |
| C级 | 结构性问题（节奏/逻辑/人设），修改需1-2小时 | 打回→写手重写→次日重审 |
| D级 | 方向性错误（偏离主线/核心设定矛盾/OOC） | 建议废除→上报主编→剧情组重新出纲 |

**重要**：如果连续3章出现C级 → 不是写手的问题 → 检查章纲是否出了问题。

## 二、二审：文字编辑（文字层面）

### 二审润色五维度

**维度1——语句通顺（必须改）**：
- 拗口/歧义/重复的句子 → 必须修正
- 修正目标是"读起来顺"，不是"改得花哨"
- 判断标准：一句读了三遍才懂 → 这句子必须改

**维度2——表达优化（可以改）**：
- 用更精准/更有画面感的词替换平淡表达
- 不改风格——写手是简洁风就保持简洁，是华丽风就保持华丽
- 示例："他很生气" → 不改（如果写手是简洁风）；"愤怒像一团火在他胸口烧" → 不改（如果写手是华丽风）

**维度3——冗余删除（应该改）**：
- 删掉"删了也不影响信息传递"的内容
- 删除对象：重复强调同一信息、无信息量的过渡句、空泛的形容词堆砌
- 慎重：如果一段"看似冗余"的内容在塑造氛围或角色 → 可能是故意的 → 保留

**维度4——节奏调整（精细调整）**：
- 句子层面调整长短句交错
- 动作场景：检查是否短句为主（15字以内），长句会拖慢节奏
- 日常场景：检查是否有足够的节奏变化（全是短句=紧绷，全是长句=沉闷）
- 抒情场景：检查是否有1-2个长句（不超过80字）作为情绪释放

**维度5——情绪增强（画龙点睛）**：
- 在高潮/泪点/燃点处加强文字的感染力和密度
- 方法：在情绪峰值加1-2句具体感官描写
- 注意：只能"增强"不能"添加"——情绪本身必须来自内容，文字只是放大镜

### 润色原则

1. 保留写手风格——不是在重写，是在打磨。改完后读者应能"认出是谁写的"
2. 有些句子"不够好但只要没错"就可以过——不要追求每句都是金句（金句密度太高=审美疲劳）
3. 对照文风指南——确保不偏离全书统一风格（特别是禁用句式检查）
4. 如果连续3章对同一个写手提出同样的文字问题 → 问题在文风指南没说清楚 → 反馈给负责人

### 润色红线（不自行修改，上报主编）

- 文风与文风指南严重偏离（如全章都在用禁用句式）
- 需要改动的文字超过全文30%（基本需要重写）
- 写手风格与标准风格严重冲突

## 三、三审前半：校对（格式层面）

### 校对五维度

**1. 错别字**：
- 同音字（她在/他再、的/地/得）
- 形近字（己/已/巳、未/末）
- 拼音输入错误（工具可抓大部分，人工复核剩余）
- 方法：工具初筛→人工通读一遍（大声读出每个字→大脑不会"自动修正"）

**2. 标点规范**：
- 中英文标点混用（中文正文只能用中文标点）
- 引号不匹配（" " 配 " " / ' ' 配 ' '）
- 省略号：中文省略号是……不是...
- 破折号：中文破折号是——不是--
- 对话格式统一

**3. 格式统一**：
- 段落间距一致（不能有的空1行有的空2行）
- 缩进统一
- 对话格式与全书保持一致

**4. 专有名词一致性**（对照术语表逐项检查）：
- 人名：全书统一（不能"艾拉"变"艾娜"）
- 地名：全书统一（不能"西泉要塞"变"西泉哨站"除非是不同地点）
- 技能名：全书统一（"骷髅复苏""骷髅召唤""骷髅复活"是三个不同技能）
- 物品名、势力名：全书统一

**5. 数字格式**：
- 数字和单位使用统一（"三具骷髅" vs "3具骷髅"——确定全书规则并统一）

### 工作原则

- 先工具后人工：校对软件初筛 → 人工复核
- "看习惯了"是校对最大的敌人——疲劳时强制休息。连续工作超过3章必须休息15分钟
- 新出现的专有名词 → 立即登记到术语表（不要"等下再记"——一定会忘）
- 不确定的 → 标注"待确认"而不是强行修改（特别是地名/技能名，改错了比没改更糟）

### 严重错误加急标记

以下错误触发加急标记 → 通知主编：
- 主角名字写错
- 关键技能名写错
- 重要道具名写错（与后续剧情关键物品相关）
- 关键地名写错（导致读者/后续章节混淆）

### 术语表格式

```
【类型】人名/地名/技能名/物品名/势力名/其他
【标准写法】准确的中文名称
【别称】（如有）角色私下叫法/简称
【禁用写法】绝对不能用的错误写法
【首次出现】第X章
【备注】特殊注意事项
```

## 四、终审：主编（最终裁决）

### 终审检查清单（四层）

**第一层——底线检查（不过=直接D级）**：
- [ ] 是否有政治敏感内容？
- [ ] 是否有违反红线清单的设定？
- [ ] 主角是否有OOC行为？（性格突变无理由）
- [ ] 核心设定是否自相矛盾？

**第二层——质量检查（每项不合格扣2-3分）**：
- [ ] 本章推进了至少一个剧情目标吗？
- [ ] 章末有有效钩子吗？（信息钩子或情境钩子，不能是假钩子）
- [ ] 信息增量够吗？（至少1个新信息/新进展，3个以上为佳）
- [ ] 描写密度够吗？（有画面感的描写，不只是叙述和对白）

**第三层——一致性检查（每项不合格扣1-2分）**：
- [ ] 角色行为符合当前成长阶段吗？
- [ ] 技能/等级数值与前文一致吗？
- [ ] 地理/时间与前文一致吗？
- [ ] 本章的世界设定与前文一致吗？

**第四层——读者体验检查（主观但必须回答）**：
- [ ] 读完本章后，想立刻点下一章吗？（不想=可读性有问题）
- [ ] 在乎这章里发生的事吗？（不在乎=情感投入有问题）
- [ ] 这章最让人印象深刻的画面/台词是什么？（说不出来=描写不够）
- [ ] 如果是追更读者，这章会让你弃书吗？

### 终审评级标准

| 等级 | 分数 | 标准 | 处理 |
|:--:|:--:|------|------|
| A级 | >= 24 | 底线全部通过 + 质量全合格 + 至少1个亮点 + 读完想追更 | 直接发布 |
| B级 | 18-23 | 底线通过 + 质量1-2项轻微不合格 + 修改<=30分钟 | 确认修改后发布，不需重审 |
| C级 | 12-17 | 底线通过但质量3项以上不合格 或 1项严重不合格 | 打回修改，修改后重新终审 |
| D级 | < 12 | 底线不通过 或 系统性质量问题（通篇纯叙述无画面） | 退回重写，基本推倒重来 |

**B级→A级的常见修改**：
- 加一个具体画面（把"他很紧张"改成身体反应）
- 加一个有效钩子（把"他不知道接下来"改成具体悬念）
- 加一段对话让角色声音更清晰

### 发布节奏判断

终审不只是"这章好不好"，还要判断"这章现在发合适吗"：

| 判断维度 | 问题 |
|---------|------|
| 剧情节奏 | 连续3章都是低信息增量的日常？→ 下一章必须是高潮或转折 |
| 读者期待 | 上一章结尾是大悬念？→ 这一章必须回应，不能跳去讲支线 |
| 存稿状态 | 存稿低于5章？→ 不能批准爆更节奏 |
| 章节类型平衡 | 连续5章战斗？→ 读者需要喘息，中间需要1章日常互动 |
| 情绪曲线 | 连续释放/温馨？→ 读者会无聊，需要紧张信号 |

### 争议裁决流程

当写手和编辑有分歧时，主编做最终裁决：

1. 先听写手为什么要这么写（不是"我觉得好"——是"我想达到什么效果"）
2. 再听编辑为什么觉得不行（不是"写得不好"——是"读者可能会怎样"）
3. 写手意图对但没实现好 → 保留方向、改进执行
4. 写手意图本身有问题 → 驳回 + 给出替代方向
5. 裁决必须在24h内做出——写手不能无限期等待

## 五、编辑反馈规范

### 三要素反馈法

每条问题必须包含三个要素（缺一不可）：

```
【位置】第X段第Y句起
【问题】什么问题——用读者感受描述（"这里读者可能会觉得角色行为不合理"）
【方向】往哪个方向改——给1-2句示范
```

### 合格与不合格对比

**不合格反馈**：
- "这章节奏不太好"（没有位置+没有方向）
- "整体感觉有点水"（没有位置+没有方向）
- "写得不如上一章"（没有位置+没有方向+打击性）

**合格反馈**：
- "第8-12段的矿渣堆巡逻描写可以精简到2段——读者关心的是主角的下一步选择，不是巡逻的细节。把第13段林夜摊开地图做决定的段落提前到第8段，节奏就对了。"

### 亮点标注

不仅要找问题，也要找亮点：
- 标注写得好的段落 → 告诉写手"这里写得好，原因是XX"
- 标注进步的迹象 → "这次对话的遮名辨人测试通过了，继续保持"
- 标注可复用的写法 → "这个用环境写情绪的手法可以在其他地方复用"

## 六、各环节日志模板

### 一审日志
```
【章节】第X章 / 写手 / 日期
【等级】A/B/C/D
【主要问题】具体位置+问题+建议方向
【亮点】做得好的地方
【修改用时预估】B级：X分钟 / C级：X小时
【趋势关注】这个写手在变好/变差/原地踏步？
```

### 二审输出
```
【稿件标识】第X章 / 写手名
【润色类型】标注+改后文字（在原文上直接修改）
【主要修改点】通顺X处/优化X处/删冗余X处/节奏X处/情绪增强X处
【保留说明】"写得不错但犹豫要不要改"的段落→保留并说明为什么保留
【文风合规】是否与文风指南一致→如有偏离标注位置+具体问题
```

### 校对输出
```
【校对】第X章
【错别字】位置→错误→正确（X处）
【标点错误】位置→错误→正确（X处）
【格式问题】位置→问题→修正（X处）
【专有名词不一致】位置→错误写法→标准写法（X处）
【数字格式不统一】位置→问题→修正（X处）
【新增术语】新出现的专有名词→建议的标准写法→登记到术语表
【加急标记】（如有）严重错误通知
【校对状态】通过/修改后通过
```

### 终审日志
```
【章节】第X章
【终审等级】A/B/C/D
【主要问题】（如有）具体位置+问题描述+修改方向
【亮点】（如有）本章做得最好的部分
【发布建议】立即发/修改后发/压稿等待时机
【审稿用时】从开读到完成判定的时间
【审稿状态】放行/打回/退回重写
```

## 七、质量趋势追踪

每月汇总一次：

- A/B/C/D级章节占比变化
- 最常见的打回原因 TOP3
- 哪些写手的稿件质量在上升/下降
- 哪些类型的问题在反复出现（→ 流程问题，需要追责到编辑组）

**预警阈值**：如果C+D级占比连续3章超过30%，自动触发质量专题会。
