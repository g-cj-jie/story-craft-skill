# 写作技法手册

## 一、画面感：让读者"看到"而非"被告诉"

**核心原则**：每当想写一个情绪形容词（紧张/愤怒/恐惧/高兴），停下来，写"这个情绪让身体发生了什么"。

| 避免（告之） | 替代（展示） |
|-------------|-------------|
| 林夜很紧张。 | 林夜的手心在发潮。他第三次用袖口擦手，布已经湿透了。 |
| 她非常愤怒。 | 她的手指一根根收紧，指节发白。 |
| 他很害怕。 | 他的呼吸卡在喉咙里，咽不下去也吐不出来。 |
| 她很高兴。 | 她压住嘴角，但眼睛出卖了她——眼角皱起了细纹。 |

**描写配额**（每1000字至少包含）：
- 视觉描写 3 处
- 听觉描写 1 处
- 触觉/温度描写 1 处
- 嗅觉描写 0.5 处（战斗场景翻倍）

## 二、声音感：角色对话差异化

**核心信条**：遮住名字，能认出每句话是谁说的。

### 角色对话风格卡模板

每个核心角色应建立：

```
【角色名】
【说话节奏】短句/长句/陈述/反问/感叹——以哪个为主？
【句式偏好】命令式/疑问式/条件式/陈述式？
【标志词/口头禅】该角色常用但其他角色不用的词
【词汇层级】市井/普通/文雅/学术/军事
【典型句长】一句话通常多少字
【禁忌用词】该角色绝对不会说的词或句式
【情绪波动时的变化】生气/紧张/高兴时，说话方式如何变化？
【对话示例】至少3句不同情境的典型台词（日常/紧张/情感）
```

### 角色声音示例（本作）

| 角色 | 说话特征 |
|------|---------|
| 林夜 | 短句多，陈述句多，"能少说就少说"。在游戏里孤独了20年，不习惯长篇表达。越在意的事越简短。 |
| 艾拉 | 直接、带刺，每句话都像在嚼东西。习惯了野外生存的简洁。 |
| 马库斯 | 说话时自我打断和修正。在脑子里和经文做比较，措辞谨慎。 |

**自检方法**：写完对话后，把所有"XX说"遮住，只读台词。能分辨每句话是谁说的吗？不能 = 需要重写。

### 对话打磨四维测试

**测试1——遮名辨人**：每句话的风格指向唯一的说话者。有多句话可以互换说话者 = 对话风格雷同。

**测试2——信息密度**：这段对话同时完成了以下至少两项吗？
- 塑造角色（让读者更了解角色的性格/价值观/背景）
- 推进剧情（对话本身导致了什么变化/决策/行动）
- 释放信息（读者从对话中获得了什么新信息）
- 制造/缓解冲突（对话改变了角色间的关系状态）
- 只完成一项 = 有"水"的嫌疑

**测试3——潜台词**：至少有一个角色在"不完全诚实"——善意隐瞒/自我保护/试探/误导。嘴上说的和心里想的有差距 = 读者有解读空间。完全直白 = 太浅（除非该角色设定就是心直口快型）。

**测试4——呼吸感**：对话中有非语言节奏吗？
- 有沉默/停顿（不是每句话都立刻接上）
- 有打断（角色不应该总是说完完整句子）
- 有动作穿插（说话时在做什么——喝茶/看窗外/拨弄武器）
- 有情绪变化（对话开始和结束时的情绪状态不同）

### 不同对话类型的打磨要点

| 对话类型 | 关键关注点 |
|---------|----------|
| 深度对话（两人交心） | 节奏必须慢——有沉默、有停顿、有"说不下去"。不要让两个角色轮流发表长篇大论。 |
| 多人对话（3人+） | 每人必须有明确的"说话欲"差异——A主导、B偶尔插话、C沉默但态度在动作里。 |
| 信息揭露对话 | 信息不能一次性全倒——要有"追问→不情愿地说→再追问→揭示关键信息"的过程。 |
| 谈判/对峙对话 | 每句话都要改变权力关系——谁的筹码更多？谁在让步？地位变化必须在对话中体现。 |
| 情感对话 | 越重要的话越"说不出来"或"说不完整"。不会有人用完美措辞表达最深的感情。 |

## 三、空间感：战斗场景的读者认知负荷

### 战前必答（每次战斗写作前填写）

```
【战斗类型】单挑/团战/Boss战/追杀/守城/突围
【参战角色】当前等级+核心能力+在本场战斗中的角色定位
【战斗地点】具体场景→地形特征→可利用的环境元素→空间限制
【战斗目标】所有人的目标（不只是"打赢"——有人想拖时间/有人想偷东西/有人想逃跑）
【战力对比】我方优势/敌方优势/决定胜负的关键因素
【情绪弧线】紧张→...→高潮→...→收束
【战斗阶段】这场战斗分几个阶段？每个阶段的转折点是什么？
```

### 空间锚定方法

**战斗开始前（2-3句锚定空间）**：
- 地形：具体化——不是"森林"，是"老橡树林，树冠遮天，地面蕨类及腰"
- 距离：具体数字——"约四十步外"，"不到十步"
- 方向：明确位置——"林夜背靠矿壁，敌人从东侧坑道逼近"

**战斗中每3-4段更新一次位置信息**：
- "铁皮被击退到了左侧碎石堆"
- "黑爪绕到了目标身后十五步"
- 方法：想象在用无人机拍摄，镜头不能一直对着主角的脸

### 杜绝回合制的四个技术

**技术1——用"同时"替代"然后"**：
- 错误："林夜放出骨矛。然后敌人闪避。然后骷髅从侧面攻击。"
- 正确："林夜放出骨矛的同时，铁皮已经从侧面碎石堆后绕出。骨矛是佯攻——真正的杀招在骷髅手里。"

**技术2——嵌入决策瞬间**：
不在每个动作之间写"XX想了一下"，而是在关键时刻插入1-2句决策：
"骨矛偏了。不是没瞄准——是故意偏的。他需要那根骨矛钉在敌人身后的树干上，形成夹击角度。"

**技术3——环境参与战斗**：
每场战斗至少利用3次环境元素。地形障碍/高低差/光线/天气/散落的物品/之前战斗留下的痕迹。
"他不需要在黑暗中看见敌人——骷髅在黑暗中的感知比眼睛可靠。"

**技术4——战斗有节奏起伏**：
不是从头紧张到尾。标准节奏链：压制→反击→僵持→突破→追击→意外→决胜。
每个阶段1-3段的长度，形成"短-短-稍长-短-稍长-短-最长"的段落节奏。

### 不同战斗类型的节奏设计

| 类型 | 节奏 | 篇幅 | 关键特征 |
|------|------|:--:|---------|
| 偷袭/伏击 | 极快 | 3-5段 | 前面蓄力，瞬间爆发，快速收束 |
| 单挑对决 | 中速+层层推进 | 10-20段 | 三个阶段：试探→全力→决胜，每阶段都有小转折 |
| Boss战 | 慢起→加速→高潮→余波 | 1-3章 | 多阶段：侦查→策略→多阶段战斗→余波，每阶段转换时改变战场环境 |
| 以寡敌众 | 快节奏切换 | 5-10段 | 在多个威胁之间快速切换，制造"同时应对多个方向"的紧张感 |
| 碾压/收割 | 干脆利落 | 3-5段 | 重在"爽"，不拖泥带水，压倒性优势的展示 |

### 战斗后检查清单

- [ ] 技能使用是否符合当前等级？（有没有用尚未解锁的技能？）
- [ ] 法力消耗是否合理？（有没有"无限蓝"的问题？）
- [ ] 兵力/资源变化是否追踪？（损失了多少→还剩多少→需要恢复多少？）
- [ ] 空间感是否清晰？（读者是否知道谁在哪？）
- [ ] 是否有环境互动？（至少3处利用环境）
- [ ] 战斗节奏是否有起伏？（不是从头紧张到尾）
- [ ] 是否有"回合制"段落？（找出所有"A→B→A→B"模式并改写）
- [ ] 战斗后果是否在后续章节体现？（伤势/消耗/装备损失）

### 战斗中的情绪嵌入

战斗不只是力量对抗，是意志和情感的对撞：
- 主角情绪变化：冷静→受挫→调整→愤怒/坚定→突破
- 敌人情绪变化：轻视→认真→恐惧→绝望/狂怒
- 关键时刻插入1-2处"慢镜头"——放慢节奏，写主角的感知和决策

## 四、章末钩子

每章至少用一种钩子：

**信息钩子**：揭示一个让读者意外的新信息。
"他低头看着那张纸，上面的名字他已经三年没见过了。"

**情境钩子**：把角色放在一个危险的/未知的/无法回避的位置。
"门从外面锁上了。灯灭了。"

**禁止假钩子**："他不知道接下来会发生什么"——读者也不在乎。

## 五、章节自检清单（提交前逐条确认）

### 第一步：骨架检查
- [ ] 是否严格按章纲的"核心目标"完成本章？
- [ ] 本章是否推进了至少一个剧情目标？（不能是纯过渡章）
- [ ] 章末是否有有效钩子？（信息钩子或情境钩子，不能是假钩子）

### 第二步：一致性检查
- [ ] 所有出场角色的台词是否可以遮名辨认？
- [ ] 角色行为是否符合当前成长阶段？
- [ ] 是否有与世界观设定矛盾的内容？
- [ ] 技能/等级数值与前文一致吗？（有疑问→查设定文档，不要凭记忆）

### 第三步：质量检查
- [ ] 字数是否在3000-5000字范围内？
- [ ] 是否至少有3处画面感描写？（不只是叙述和对白）
- [ ] 是否有"水字数"段落？（删了也不影响信息传递的内容）
- [ ] 错别字自查（通读至少一遍）
- [ ] 战斗场景是否有空间感？（读者知道谁在哪、在做什么）
- [ ] 章节内无序号标记？（无 `## 一`、`1.`、`第一幕` 等编号分段，场景切换用空行/分隔符/叙事过渡）

### 第四步：自我评分
- 这章自己打几分（1-10）？
- 不到7分，差在哪？能改吗？

## 六、常见写作错误（新人特别关注）

1. **千人一面**：遮住名字分不出谁在说话 → 查角色声音设定
2. **告之而非展示**：写"XX很紧张" → 改为写身体反应
3. **战斗回合制化**：A放技能→B受伤→B放技能→A受伤 → 加环境变化和位置移动
4. **章末忘钩子**：过渡章尤其容易忘 → 即使非高潮章也要有钩子
5. **信息密度过低**：整章写完读者没有新收获 → 至少有1个新信息/新变化
6. **过度模仿他人**：模仿得太像 = 失去自己 = 文风不统一

## 七、文风指南维护

### 文风指南模板

```
1. 叙事距离：第一人称/第三人称有限/第三人称全知？
2. 句子节奏：动作场景（15字以内短句）、日常场景（允许30-50字复合句）、抒情场景（允许长句但不超过80字）
3. 描写配额：每1000字至少包含视觉3处、听觉1处、触觉1处、嗅觉0.5处
4. 对白占比：日常章节30-40%，战斗章节不超过20%
5. 段落长度：网文不宜超过150字，动作场景每段不超过80字
6. 禁用句式：列出本文禁止使用的套路句式（如"只见""话说""与此同时""就这样"等）
7. 金句密度：每章至少1句能让读者划线/截图的句子
```

### 维护原则

- 如果写手连续3次在同一个问题上出错 → 不是写手的问题，是《文风指南》没说清楚
- 如果编辑连续3章对同一写手提出同样的文字问题 → 问题在文风指南，反馈给负责人

## 八、写法反馈方法

收到稿件时，不要只说"写得不好"。按三层递进反馈：

1. **第一层——指出具体位置**："第X段第Y句"而不是"前面部分"
2. **第二层——说出读者感受**："这里读者可能会跳过"而不是"写得不好"
3. **第三层——给出修改示范**：直接写一段改后版本，而不是"应该更有画面感"

### 反馈格式模板

```
【稿件标识】第X章 / 写手 / 日期
【具体位置】第X段第Y句起
【读者感受】读者可能的反应
【问题类型】画面感/声音感/空间感/节奏/钩子
【修改示范】直接给出改后版本
【学习要点】这次修改的核心技巧是什么
```

### 文风样本格式

```
【样本来源】第X章第Y段
【样本原文】（原文段落）
【为什么选这段】这段在XX方面做得好，原因是...
【可复用技巧】写手在其他地方可以怎么用这个技巧
```

## 九、写作笔记模板（每日反思用）

```
【日期】X月X日
【今天写了】第X章 / 类型
【最顺利的段落】哪段写得顺手？为什么？
【最卡的段落】哪段写不下去？最后怎么解决的？
【今天学到】一个具体的写作技巧
【需要继续改的】今天被指出什么错误？怎么避免再犯？
```
