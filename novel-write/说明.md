# novel-write 说明

## 功能定位

长篇小说内容编写Skill，负责将章纲转化为正文。

## 两种工作模式

| 模式 | 触发条件 | 输入 | 输出 |
|------|---------|------|------|
| 首次写作 | leader 分配新章纲 | 上下文包+章纲 | 正文+变动清单 |
| 审查后修改 | review 评分<80分 | 原文+问题清单 | 修改后正文+修改回应+变动清单 |

## 核心约束

- 每章3000-5000字
- 场景不超过3个
- 每章必须输出变动清单（情节/子剧情/伏笔/人物/势力变化）
- 修改模式必须逐条回应审查问题
- 最多修改3次，3次仍未通过由 leader 决策

## 文件结构

```
SKILL.md                # 本文件（极简入口）
说明.md                 # 中文说明
references/
  writing-specs.md      # 写作规范（语言/场景/节奏/伏笔/人物/禁止行为）
  output-format.md      # 输出格式（首次模式/修改模式/变动清单）
```
