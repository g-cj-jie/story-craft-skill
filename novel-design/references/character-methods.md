## 一、主角11维度档案模板（来源：protagonist-designer）

```
【维度1：身份标签】
  3个词概括——读者记住主角的锚点
  30个字说清人设——给完全没读过的人介绍主角

【维度2：性格核心】
  主导性格（默认行为模式）
  内在矛盾（两个冲突欲望的拉扯——角色深度来源）
  性格光谱（在不同压力下的表现）：
    - 日常状态下的性格
    - 压力下的性格变化
    - 极端压力/濒死时的性格暴露

【维度3：背景与创伤】
  穿越前的人生（至少300字）
  核心创伤事件（塑造性格的关键事件）
  穿越前的未完成事件（让他对某些东西特别敏感/执着）

【维度4：欲望与恐惧】
  表层欲望：他以为他想要的（变强/活下去/回家）
  深层欲望：他真正需要的（被认可/找到归属/证明存在有意义）
  最大恐惧：他最怕发生的事
  欲望的演化：表层欲望如何逐步让位于深层欲望（全书层面）

【维度5：能力与限制】
  核心优势：性格/经验/思维方式的优势（不只是金手指）
  核心弱点：他永远不擅长的东西（真实、持续的限制）
  独特能力：只有他能做的事（金手指+个人特质=独特性）
  能力边界：当前阶段绝对不能做的事

【维度6：道德框架】
  道德底色：利己/利他/功利/道义——默认倾向
  道德弹性：在什么情况下会突破自己的底线
  绝对禁忌：无论如何都不会做的事（3-5条）
  道德演化：道德框架会随成长变化吗？

【维度7：认知模式】
  决策方式：直觉型/分析型/经验型
  信息处理：如何获取和评估信息
  认知偏差：他的"主观滤镜"——什么类型的信息会高估/低估
  学习方式：通过试错/观察/阅读/被教训

【维度8：人际关系模式】
  信任模式：容易信任还是很难信任？信任建立/破裂的条件
  依赖程度：独立解决还是寻求帮助？
  对待盟友的方式：工具性/互惠性/情感性
  对待敌人的方式：消灭/利用/转化/回避
  情感表达：直接还是含蓄？如何表达关心/不满？

【维度9：说话方式（声音指纹）】
  句长偏好：长句/短句/混用
  句式偏好：陈述/反问/条件/命令
  标志词/口头禅（每个阶段可能不同）
  情绪波动时的变化：紧张/愤怒时的说话特征
  绝对不说的词/句式

【维度10：行为模式（典型情境下的反应）】
  面对强敌时：正面对抗/迂回/撤退/谈判
  面对求助时：直接帮/谈条件/先评估再决定/回避
  面对背叛时：报复/冷处理/理解/预先防范
  面对失败时：自责/分析/愤怒/冷静
  面对赞美时：接受/否认/尴尬/忽视

【维度11：成长弧线】
  起点（第1章）：初始状态
  阶段1（第X-Y章）：触发事件→成长到什么状态
  阶段2（第A-B章）：触发事件→成长到什么状态
  ...
  终点（全书最后）：最终状态
  每个阶段之间：是什么事件推动成长？（不只是"变强"——性格/认知/关系都必须成长）
```

### 主角设计审查标准

**基础审查（设计阶段）**：
- [ ] 主角有真实的缺点吗？没有→设计失败（没缺点=没成长空间=读者不共情）
- [ ] 主角是"做选择的人"还是"被事情推着走的人"？后者→设计失败
- [ ] 主角的成长只是"变强"吗？是→需要增加性格成熟、认知提升、关系深化
- [ ] 金手指是否替代了主角的努力和选择？是→金手指必须只是放大器
- [ ] 读者能在第1章就想支持他吗？不能→动机/共鸣设计不足

**每章审查（写作阶段）**：
- [ ] 主角的行为符合当前成长阶段吗？
- [ ] 主角的决策有充分动机吗？
- [ ] 主角在这一章做了至少一个选择吗？
- [ ] 主角在这一章展示了他的某个弱点或局限吗？
- [ ] 金手指是"帮助他实现他的选择"还是"替代他做选择"？

## 二、金手指设计原则（来源：protagonist-designer）

金手指的设计目标是"让主角的独特选择成为可能"，不是"让主角不需要做选择"。

| 好的金手指 | 坏的金手指 |
|----------|----------|
| 提供了其他角色没有的选项 | 让所有选项中只有一个是对的 |
| 使用需要付出代价和决策 | 使用没有代价，所以"为什么不用" |
| 放大了主角的性格优势 | 替代了主角的性格，金手指=主角 |
| 有明确的限制和边界 | 无限/万能/遇什么都能解决 |
| 与主角的弱点形成互补但不覆盖 | 直接消除了主角的唯一弱点 |

### 主角四维成长检查（每卷）

如果某一卷只有力量成长→这卷的主角成长是"扁平"的。

| 维度 | 本卷成长 | 表现方式 |
|------|---------|---------|
| 力量成长 | 等级/新技能/新装备 | 战力对标上一级的变化 |
| 性格成长 | 克服了一个性格缺陷/获得了新视角 | 以前会X，现在会Y |
| 认知成长 | 对世界/对自己/对敌人有了新理解 | 知道了某个真相/改变了某个误解 |
| 关系成长 | 与至少1个角色关系发生了实质性变化 | 信任/亲密/敌意的变化 |

## 三、核心角色档案模板（来源：character-director）

每个核心角色必须包含以下字段（缺一不可）：

```
【角色名】
【身份标签】3个词以内——读者记住这个角色的锚点
【性格核心】一个主导性格 + 一个内在矛盾
  - 主导性格：角色默认的对外行为模式
  - 内在矛盾：角色内心两个冲突欲望的拉扯
【声音指纹】说话节奏+口头习惯+禁用词
  - 节奏：长句/短句/陈述/反问
  - 标志词：这个角色常用但其他角色不用的词
  - 禁用：这个角色绝对不会说的句式
【欲望与恐惧】
  - 表层欲望：角色自己以为想要的
  - 深层欲望：角色真正需要的
  - 最大恐惧：角色最害怕的事
【角色弧线】从哪个状态→成长到哪个状态
  - 起点：故事开始时角色的状态
  - 终点：计划中这个故事结束时角色的状态
  - 关键转折点：至少3个改变角色的事件
【能力与限制】
  - 核心能力：角色最擅长什么
  - 核心弱点：角色最不擅长什么（真实、持续的限制，不是"太善良"这种伪弱点）
【人际关系】与至少3个其他角色的关系定义（具体到"他欠X一条命""他看不惯Y但尊重Y的能力"）
```

### 角色差异化四维检查

新角色必须与所有已有角色做差异化比对：

| 检查维度 | 方法 | 不合格判定 |
|---------|------|----------|
| 性格重叠 | 遮住名字看性格描述，两个角色有区别吗？ | 说不出区别→合并为一个角色 |
| 功能重叠 | 新角色在剧情中的功能，现有角色能做到吗？ | 能→不需要新角色 |
| 声音重叠 | 遮住名字读台词，能分出谁在说话吗？ | 分不出→对话风格需要差异化 |
| 关系重叠 | 新角色与主角的关系，是否和已有角色雷同？ | 雷同→调整关系定位 |

**强制规则**：能不能用现有角色解决？能→不要新增角色。每个新角色都必须有"非他不可"的理由。

### OOC判断标准

- 不是"角色做了一件读者不喜欢的事"= OOC
- 而是"角色做了一件没有充分动机的事"= OOC
- 角色可以成长、可以改变——但必须有剧情触发，不能突变

### 角色出场节奏

| 阶段 | 可容纳重要配角数 | 说明 |
|------|:-------------:|------|
| 第1-10章 | 主角+2个重要配角 | 读者还在熟悉主角，配角太多会分散注意力 |
| 第11-30章 | 主角+4个重要配角 | 逐步引入，每个新角色至少间隔5章 |
| 第31-60章 | 主角+6个重要配角 | 核心班底基本建立 |
| 第61章+ | 按需引入但每次只引入1个 | 新角色必须附带至少2章展开 |

## 四、配角分级体系（来源：side-character-designer）

| 级别 | 数量 | 戏份占比 | 设计深度 | 退场审批 |
|------|:--:|:------:|---------|---------|
| S级配角（二号位） | 1-2人 | 20-25% | 完整角色档案+独立弧线 | 总编审批 |
| A级配角（核心班底） | 3-5人 | 10-15%每人 | 完整角色档案 | 总编审批 |
| B级配角（常驻配角） | 5-8人 | 3-5%每人 | 简化档案（6字段） | 人物总监审批 |
| C级配角（功能性） | 不限 | 1-2%每人 | 最小档案（3字段） | 功能完成后自然退场 |
| D级配角（龙套） | 不限 | <1%每人 | 名字+1个特征 | 可直接退场 |

**S+A+B级总数不超过12人**，超出→读者记不住。

### 配角四维差异化检查

每个配角必须在以下四个维度与所有同级配角有区分：外貌（遮住名字只看外貌描述能认出）、声音（遮住名字只读台词能分出）、功能（有没有其他配角能替代）、关系（与主角的关系是否雷同）。

### 配角档案模板

**S/A级配角（完整档案）**：姓名+绰号 / 外貌特征（3个具体记忆点，至少1个不寻常） / 声音特征（节奏+标志词+口头禅） / 性格核心（主导性格+内在矛盾） / 个人欲望（独立于主角） / 与主角的关系（类型+历史+关系秘密） / 角色弧线（起点→转折→终点） / 高光时刻（至少1章） / 退场计划

**B级配角（简化档案）**：姓名+身份 / 外貌特征（2个记忆点） / 声音特征（1个标志性表达） / 与主角的关系 / 剧情功能 / 高光时刻（至少1个段落） / 退场时机

**C级配角（最小档案）**：姓名+身份 / 1个记忆点 / 剧情功能

### 配角登场与退场规范

- **登场**：S/A级配角出场前至少提前5章铺垫（传闻/他人提及/线索暗示）；B级提前1章铺垫
- **退场**：所有配角退场必须有"最后一幕"（哪怕只有1段交代），不能"突然就不提了"
- **被遗忘检查**：超过10章未出现的配角→读者忘了→需要"唤醒"或安排退场

### 每卷配角生态审查

- [ ] 同级别配角之间有没有功能重叠？
- [ ] 有没有"用完就扔"的配角？
- [ ] 配角出场有没有"渐入渐出"？
- [ ] S+A+B级总数是否超过12人？
- [ ] 有没有配角"抢了主角风头"？
- [ ] 每个配角最近5章有出场吗？（超过10章→需要唤醒或退场）

## 五、关系追踪方法论（来源：relationship-manager）

### 关系档案模板（每对角色）

```
【角色A】↔【角色B】
【关系类型】单一类型/复合类型
【当前关系强度】
  - 信任度：0-100
  - 亲密度：0-100
  - 敌意度：0-100
  （信任度和亲密度可共存，如"信任他的能力但不亲近他的为人"）
【关系起点】第X章——两人怎么认识的
【关系历史】按时间顺序的每次关键互动：
  ├── 第X章：初次见面——A对B的印象是XX / B对A的印象是YY
  ├── 第Y章：共同经历事件——关系变化为...
  ├── 第Z章：发生分歧——关系退步/进步...
  └── 最新：第N章——当前状态
【关系秘密】两人之间独有的、只有他们知道的事
【关系发展方向】计划中关系的演变路径（变好/变坏/破裂/转为其他）
【下一个关系转折点】计划在第X章发生什么事件导致关系变化
```

### 关系变化规则

关系变化必须有"关系事件"触发：

| 关系事件类型 | 信任度变化 | 亲密度变化 | 示例 |
|------------|:-------:|:-------:|------|
| 救命之恩 | +20-30 | +10-20 | A救了B的命 |
| 背叛 | -30-50 | -20-40 | A在关键时刻选择利益而非B |
| 共同战斗胜利 | +5-15 | +5-10 | 一起打赢了一场硬仗 |
| 意见分歧 | -5-15 | -5-10 | 在重要决策上分歧 |
| 秘密共享 | +10-20 | +15-25 | 一方告诉另一方一个秘密 |
| 长期未见 | 不变 | -5-10 | 时间造成的疏远（可恢复） |
| 牺牲/付出 | +15-25 | +15-25 | 一方为另一方做出了实质牺牲 |

**规则**：单次变化不超过50（除非全书级重大事件）；关系不能"跳跃"（从-20到+50必须经过中间状态）；变化后必须有至少1章体现新状态。

### 每章关系五检

1. **称呼检查**：A对B的称呼是否与当前关系一致？（从"大人"到直呼其名需要关系事件）
2. **态度检查**：互动态度是否与上次结束时一致？（上次还在冷战→这次不能直接热络）
3. **信息检查**：A对B说的事，以他们的关系，A会说吗？（不信任的人不分享秘密）
4. **遗忘检查**：重要的历史关系是否被遗忘？（师徒/救命之恩/背叛——这些不能忘）
5. **秘密检查**：两人之间的"关系秘密"是否还有效？

### 关系跳跃预警

- 没有关系事件，信任度/亲密度单章变化超过20
- 上次互动为负面→本次直接跳到正面（缺少和解事件）
- 上次互动为正面→本次直接跳到负面（缺少恶化事件）
- 连续10章以上没有互动但关系状态"维持不变"（实际应有时间造成的疏远）

### 关系遗忘预警

- 曾有过重要关系事件（救命/背叛/秘密共享），10章后此关系完全不再体现
- 师徒/血缘等永久性关系在50章后不再被提及或影响行为
- 两个角色之间的关系秘密被遗忘（角色做了不符合"知道这个秘密"的行为）

### 维护节奏

- **每章完成后**：更新涉及角色对的关系历史+关系强度数值
- **每卷完成后**：全关系网络健康检查，找出被遗忘的关系对（>20章无互动）和关系跳跃问题
