# 故事设计规范

## 字数层级标准（2000万字全书基准）

```
全书 2000万字
  └── 部(Part): 5部 × 400万字/部
        └── 卷(Volume): 8卷/部 × 50万字/卷
              └── 篇(Arc): 6~8篇/卷 × 6-8万字/篇
                    └── 章(Chapter): 15~20章/篇 × 3000-5000字/章
```

每层都有独立的起承转合。

## 部纲必含要素

### 篇边界定义（单一数据源）

部纲是篇边界的**唯一权威数据源**。所有其他文件（篇纲文件名、章纲标注、当前位置.md）以此份定义为准：

```markdown
## 篇边界定义
| 篇号 | 章范围 | 篇名 | 对应WOW区域/等级 |
|---|---|---|---|
| 第一篇 | ch1-10 | 穿越与新手区 | 北郡修道院 1-5级 |
| 第二篇 | ch11-25 | 艾尔文森林 | 艾尔文森林 5-10级 |
| 第三篇 | ch26-40 | 闪金镇与西部荒野 | 西部荒野 10-15级 |
| ... | ... | ... | ... |
```

**同步规则**：
- 每次生成或修改篇纲时，必须对照此表验证章范围一致
- novel-context 在边界处理时，以此表为准更新 current-position.md 的篇号
- 章纲内的篇标注必须与此表一致，发现不一致时以此表为准修正

## 部纲必含要素（续）

- 本部定位：在全书中承担的功能（开局/发展/转折/高潮铺垫/终局）
- 主线目标：本部最终目标与结束状态
- 关键转折点：每卷至少一个不可逆的重大转折（3-5个）
- 本部人物弧线：主角从X状态成长到Y状态
- 本部势力格局变化：开始时的格局 vs 结束时的格局
- 伏笔规划：新埋5-10个，填前序伏笔，跨部伏笔推进

输出到 `故事大纲/部纲/part-N.md`

## 卷纲必含要素

- 卷内弧线：开端→发展→转折→高潮→结束
- 卷内主线任务
- 篇章分解（6-8篇）：每篇的篇名/目标/字数区间
- 子剧情规划：启动/填坑/进行中各子剧情
- 人物成长节点
- 卷级伏笔操作：新埋≥3个，必填≥2个

输出到 `故事大纲/卷纲/vol-X-Y.md`

## 篇纲必含要素（核心重点）

篇是日常写作管理单元。一篇约6-8万字（15-20章）。

- 本篇定位：在卷内的功能 + 情绪曲线设计
- 篇级主线：核心问题 + 结束状态变化
- 子剧情本篇任务：每条进行中子剧情需推进程度
- 章级任务分解表：每章的目标/关键场景/伏笔操作/字数
- 节奏控制：紧张章vs舒缓章比例(建议6:4)，高潮章位置(70%-85%)
- 本篇伏笔操作清单

### 篇纲子剧情检查（硬约束）
- [ ] 至少推进50%的活跃子剧情
- [ ] 至少1条子剧情有实质进展（非一笔带过）
- [ ] 至少1条子剧情完成阶段填坑
- [ ] 子剧情之间有交集或互相影响

## 章纲必含要素

- 本章目标：推进篇主线+子剧情（一句话）
- 场景清单（1-3个）：地点/在场人物/核心事件/预计字数
- 伏笔操作：埋新/填旧/推进
- 人物状态变化
- 情感基调与节奏定位
- 上下章衔接：接续点+钩子
- 字数区间：3000-5000字

### 章纲三层叙事检查（硬约束）
- [ ] 至少1个"当前篇主线"的推进
- [ ] 至少1个"更大结构"的呼应（子剧情/伏笔/人物弧线）
- [ ] 至少1个有意义的"钩子"留给下一章

缺少任一项则章纲不合格。
