# 剧情方法论

> 来源：plot-director / main-writer / subplot-writer / pace-analyst / conflict-designer

---

## 一、章纲七字段模板（来源：main-writer）

每章章纲必须包含以下7个字段，缺一不可：

```
【字段1：章节定位】
  - 所属卷/章号
  - 章节类型：高潮/转折/战斗/日常/过渡/铺垫/收束
  - 预期字数：3000-5000字

【字段2：核心目标】
  - 本章必须完成的剧情目标（1个主要目标+最多2个次要目标）
  - 本章结束时角色/剧情到达什么状态

【字段3：情节骨架】
  - 开场：本章从什么状态开始（1-2句）
  - 核心事件：本章发生的核心事件（3-5句）
  - 转折/冲突：中间发生的转折或冲突升级（2-3句）
  - 解决/推进：事件如何发展（2-3句）
  - 结尾钩子：章末以什么结束，钩子是什么

【字段4：情绪设计】
  - 本章基调：紧张/爽/温馨/悬疑/释放/期待
  - 情绪曲线：开场情绪→中段变化→结尾情绪
  - 爽点/情绪峰值位置：在第X段左右

【字段5：信息释放】
  - 本章读者获得的新信息（至少1条，不超过5条）
  - 本章埋设的伏笔（如有）→编号+内容+计划回收章节
  - 本章回收的往期伏笔（如有）→编号+回收方式

【字段6：出场人物】
  - 每个出场角色：本章作用+关键动作/台词方向
  - 角色当前状态：在哪+什么情绪+本章结束时状态变化

【字段7：叙事意图】
  - 一句话告诉写手：这章为什么要这么写，想达到什么效果
```

**章纲质量五检**：可执行性（写手能直接开写吗）、目标明确性（一句话概括完成标准）、信息增量（读者获得什么新东西）、钩子有效性（真钩子vs假钩子）、前后衔接（开场自然接上章结尾）。

**写手反馈处理**：当反馈"写不出来"时——方向不明确则补充场景/心理/对话方向；转折太突兀则增加过渡或拆章；角色行为不合理则与人物设计沟通调整。

## 二、三幕式结构适配（来源：plot-director）

**每卷（约40章）本身就是完整三幕**：
- 第一幕（卷1-5章）：建立本卷目标+制造核心冲突
- 第二幕（卷6-30章）：冲突升级+能力成长+人际关系变化
- 第三幕（卷31-40章）：本卷高潮+收束+为下一卷种引子

**全书三幕**：
- 第一幕（卷1-3）：建立+生存+初露头角
- 第二幕（卷4-15）：成长+势力建设+多线冲突
- 第三幕（卷16-20）：决战+揭示+结局

**场景章数映射**：

| 场景类型 | 最少章数 | 标准章数 | 说明 |
|---------|:------:|:------:|------|
| 引入新角色（重要配角） | 2章 | 3-4章 | 1章出场+1-2章展开+1章建立关系 |
| 小高潮（卷内） | 2章 | 3-4章 | 1章铺垫+1-2章高潮+1章收束 |
| 大高潮（卷末） | 4章 | 5-7章 | 2章铺垫+2-3章高潮+1-2章收束与余波 |
| Boss战（精英级） | 1章 | 2-3章 | 含追踪/准备+战斗+战后 |
| Boss战（统帅级） | 3章 | 5-7章 | 含侦查+策略+多阶段战斗+余波 |
| 日常过渡 | 1章 | 1-2章 | 不可连续超过2章 |

## 三、偏离评估框架（来源：plot-director）

当写出偏离大纲但质量好的内容时，三步评估是否纳入：

1. **一致性检测**：这个偏离是否与主线结局兼容？不兼容=不能纳入
2. **机会成本**：纳入这个偏离需要删除/压缩哪些计划内容？被删内容更重要吗？
3. **读者收益**：读者会因为偏离更愿意追更吗？不会=不值得纳入

**剧情线冲突仲裁优先级**：
1. 主线推进 → 最高优先级
2. 角色弧线关键节点 → 次高优先级
3. 支线收束 → 正常优先级
4. 日常过渡/铺垫 → 低优先级，可压缩

## 四、支线设计方法（来源：subplot-writer）

### 支线分类

| 支线类型 | 长度 | 目标 |
|---------|:--:|------|
| 微型支线 | 1-2章 | 过渡+小爽点（路边遭遇战/小麻烦） |
| 小型支线 | 3-5章 | 角色展示+世界观拓展（清理矿洞/护送商队） |
| 中型支线 | 5-10章 | 配角弧光+重要收获（配角个人任务/探索遗迹） |
| 大型支线 | 10-15章 | 势力建设+核心能力升级（副本攻略/关键道具获取） |

**铁律**：支线不超过20章——超过则需重新评估是否为新主线。

### 支线设计五检

1. **独立价值检查**：删掉这个支线，读者会少获得什么？
2. **主线关联检查**：支线的收获（物品/能力/信息/关系）在主线后续中至少有1次体现吗？
3. **节奏位置检查**：支线插在高潮前会打断读者情绪——不行。
4. **读者预期检查**：读者在这个节点更想看支线还是主线推进？
5. **独立高潮检查**：支线有自己的小高潮吗？

### 支线插入时机

| 可插入 | 不可插入 |
|-------|---------|
| 主线高潮结束后（读者需要喘息） | 主线高潮即将到来时（打断节奏） |
| 两卷之间的过渡期 | 大悬念刚抛出后（读者急于知道后续） |
| 主线信息量过大需要消化时 | 主线节奏本身偏慢时（更慢会致命） |
| 主角需要展示不同能力面时 | 支线情绪与主线完全相反时 |

### 支线设计模板

```
【支线名称】
【插入节点】主线第X章结束后
【支线长度】X章
【核心冲突】这个支线的主要对抗力量
【独立价值】读者获得什么（新信息/新爽点/新角色好感/世界观理解）
【角色收获】物品/能力/信息/关系/成长
【支线高潮】必须有独立的高潮，不能全靠主线势能
【汇合方式】收获在主线第Y章体现
【情绪类型】必须与前后主线情绪互补
【可压缩性】最小版本X章
```

## 五、情绪曲线与节奏控制（来源：pace-analyst）

### 全卷情绪曲线模板（40章基准）

```
章1-5（建立期）：悬疑+期待
章6-12（推进期）：紧张+爽交替（每3章1个小爽点）
章13-18（升级期）：紧张上升+1个中爽点
章19-25（蓄力期）：紧张持续上升+悬疑加深
章26-35（高潮推进期）：紧张→激动→燃
章36-40（收束期）：释放→温馨→期待（为下一卷种钩子）
```

### 情绪类型约束

| 情绪 | 最大连续章数 | 搭配规则 |
|------|:--------:|---------|
| 紧张 | 4章 | 必须跟释放 |
| 燃/爽 | 2章 | 必须在前3章有紧张铺垫 |
| 悬疑 | 3章 | 每3章悬疑至少释放1个信息 |
| 温馨 | 2章 | 不能连续超过2章 |
| 释放 | 2章 | 必须在紧张之后出现 |
| 期待 | 不限 | 每章章末必须触发 |

### 节奏铁律

1. 每10章至少1个爽点（小高潮/战斗胜利/打脸/新能力/收服）
2. 不能连续3章"平淡"（无情绪峰值、无信息增量、无爽点）——连续3章平淡=读者开始跳章
3. 全部都是高潮=没有高潮（读者疲劳）——高潮需要蓄力
4. 高潮前必蓄力：蓄力章数 >= 高潮章数 x 50%
5. 高潮后必呼吸：每2章高潮后至少1章释放/温馨

### 信息释放节奏

| 章节类型 | 最少新信息数 |
|---------|:---------:|
| 日常章 | 1个（角色新信息/世界观细节/关系变化） |
| 推进章 | 2个（推动剧情的新信息） |
| 高潮章 | 3个（新能力展示/敌人真相/关系转折） |
| 转折章 | 3-5个（多信息同时释放制造冲击） |

**过载检测**：单章超过5个非关联新信息→读者会晕→分散到2-3章释放。

### 节奏问题定位

- "这章无聊" → 检查情绪密度：整章有情绪峰值吗？没有→加刺激点
- "节奏太快" → 检查信息释放量：单章>5个新信息→信息过载→拆分
- "节奏太慢" → 检查信息增量：读者获得了什么新东西？没有→裁剪或合并
- "高潮不够爽" → 检查蓄力：高潮前蓄力章数<50%高潮章数→蓄力不足

### 每卷节奏检测清单

- [ ] 全卷有至少3个明确的高潮点？
- [ ] 有连续3章以上同一情绪类型？（有→需要打破）
- [ ] 有连续3章以上平淡无情绪峰值？（有→红灯）
- [ ] 卷末高潮前蓄力章数 >= 高潮章数 x 50%？
- [ ] 高潮后至少有1章呼吸？
- [ ] 每10章区间内至少有1个爽点？
- [ ] 信息释放均匀分布（不能前5章密集后35章稀疏）？
- [ ] 卷末章有强力钩子？

## 六、冲突设计体系（来源：conflict-designer）

### 六类核心冲突

| 类型 | 表现方式 | 适合场景 | 过度使用风险 |
|------|---------|---------|------------|
| 生存冲突 | 生死危机、资源匮乏、环境威胁 | 战斗章/冒险章 | 连续太多→读者麻木 |
| 人际冲突 | 误会、立场对立、背叛、信任危机 | 日常章/转折章 | 动机不足→为吵而吵 |
| 内心冲突 | 道德困境、自我怀疑、两难选择 | 转折章/成长章 | 太多→读者觉得磨叽 |
| 理念冲突 | 价值观碰撞、信念对决、道路选择 | 关键转折章 | 需要铺垫不能突然出现 |
| 利益冲突 | 资源争夺、权力博弈、情报战 | 势力建设章 | 不能全是抢东西 |
| 未知冲突 | 悬疑、谜团、信息差、认知受限 | 探索章/铺垫章 | 太久不揭示→失去耐心 |

### 冲突强度五级

| 等级 | 描述 | 章数占比 | 示例 |
|:--:|------|:------:|------|
| Lv1 | 轻微摩擦/内心波动 | 20% | 日常拌嘴/短暂担忧 |
| Lv2 | 明显对抗/需要解决 | 30% | 意见分歧需调解/小规模战斗 |
| Lv3 | 激烈冲突/有严重后果 | 25% | 生死战斗/重大决策/信任破裂 |
| Lv4 | 决战/关键转折 | 15% | Boss战/角色写死/阵营选择 |
| Lv5 | 全书级别决战 | 10% | 卷末大高潮/主线结局级冲突 |

### 冲突轮换原则

- 不能连续3章同一类型冲突（如连续3章全是打斗）
- 不能连续2章同一强度（如连续2章Lv4）
- 高强度冲突(Lv3+)后必须接1-2章低强度(Lv1-Lv2)
- 内心冲突不能连续超过2章

### 冲突后果四检

每个冲突结束后检查：角色状态变化了吗？局势变化了吗？读者知道了什么新信息？后果会在后续体现吗？

以上4条都没有变化→"假冲突"（为冲突而冲突）→删除。

### 多层冲突叠加

最好的章节同时推进多个层次的冲突。例如：Boss战（生存冲突Lv3）+ 队友信任危机（人际冲突Lv2）+ 主角在命令队友冒险vs独自面对之间选择（内心冲突Lv2）= 生存+人际+内心三层叠加。

应避免："路边突然跳出一个人打主角"（只有生存冲突，无其他层次）。

### 每卷冲突升级阶梯

```
章1-10：Lv1-Lv2为主（建立冲突基础）
章11-20：Lv2-Lv3出现（冲突升级）
章21-30：Lv3-Lv4为主（冲突激化）
章31-40：Lv4-Lv5→高潮→收束
```

### 冲突网络图模板

```
主角 vs 核心反派（主线冲突）——贯穿全书
  ├── 主角 vs 中期Boss（阶段冲突）——本卷收束
  ├── 主角 vs 势力A（势力冲突）——跨卷发展
  ├── 主角 vs 队友B（人际冲突）——本卷内收束
  ├── 主角 vs 自己（内心冲突）——持续演化
  └── 主角 vs 未知（悬疑冲突）——分阶段揭示
```
