# novel-context 说明

## 功能定位

长篇小说上下文压缩引擎，是整个写作体系正确运转的核心。负责：
- 每章后增量更新7个状态文件
- 管理活跃项与归档的切换
- 到达篇/卷/部边界时生成对应级别摘要
- 确保新会话可以无缝续写（无需对话历史）

## 8个状态文件

| 文件 | 内容 | 更新方式 |
|------|------|---------|
| current-position.md | 当前写作位置 | 覆盖 |
| character-state.md | 活跃人物当前状态 | 增量 |
| faction-state.md | 活跃势力当前状态 | 增量 |
| foreshadow-ledger.md | 活跃伏笔台账 | 增量+归档 |
| subplot-state.md | 子剧情进度 | 增量+归档 |
| recent-summary.md | 最近3章摘要 | 滚动 |
| arc-brief-current.md | 当前篇简报 | 覆盖 |
| critical-data-snapshot.md | 关键精确数据快照（技能/物品/技能点/时间） | 每章覆盖 |

## 核心原则

- **增量更新**：只改变化的部分，不动无关条目
- **当前态**：记录"现在是什么样"，不记录"曾经变成过什么样"
- **可独立读取**：每个文件不依赖其他状态文件即可理解
- **上下文不随章节数增长**：第1章加载4000 token，第1000章还是约5000 token

## 文件结构

```
SKILL.md                 # 本文件（极简入口）
说明.md                  # 中文说明
references/
  state-specs.md         # 7个状态文件的格式规范
  boundary-handling.md   # 边界处理+新会话恢复流程
```
