# 跨章连续性检查

验证本章与所有前文之间的一致性。目的是在写作阶段就发现矛盾，避免读者在后续章节指出"这里不对"。

与7个状态文件的关系：状态文件记录**当前态**（人物/势力/伏笔的当前状态），追踪表记录**演变过程**（每章的状态快照，用于发现异常跳变）。两者互补——追踪表可用来交叉验证状态文件的一致性。

## 每章必查9项

1. **时间线**：本章距上章过了多久？累计时间是否正确？与旅行/移动时间是否一致？
2. **等级/实力**：是否跳变？经验/进度是否按设定累计？提升是否过快/过慢？
3. **能力/技能**：使用的能力是否已解锁？能力等级是否正确？资源消耗是否合理？
4. **随从/单位**：数量是否在公式允许范围内？如有超出，加成来源是否标注？
5. **资源**：消耗+剩余是否合理？是否有连续多章不消耗资源的"无限续航"问题？
6. **物品**：关键物品的持有/丢失/损坏状态是否连贯？
7. **伤势**：上次受的伤恢复了吗？恢复时间合理吗？伤病是否被遗忘？
8. **位置**：角色地理位置移动是否合理？有没有"瞬移"？有没有经过中间地点？
9. **伏笔**：前文伏笔是否需要在本章提醒/回收？本章是否埋了新伏笔？

---

## 判定规则

### 明确矛盾 → 标记为"错误"
存在直接数值或事实冲突，无法合理解释。

例：第N章角色等级为Lv13，第N+1章没有任何升级事件但标注为Lv14。

### 可能是故意伏笔 → 标记为"待确认"
信息看似矛盾，但有可能是作者故意埋设的伏笔或谜团。

例：某角色说了句与已知信息不符的话但后续未解释→可能是伏笔也可能是笔误。

### 数值偏差但可解释 → 标记为"需补充说明"
数值不完全一致但存在合理可能性（如未标注的加成、时间估算误差等）。

例：数量超过基础公式但可能有未标注的外部加成。

**铁律：拿不准的一律标记"待确认"，不要错把伏笔当矛盾。**

## 工作原则

- **不凭记忆**——必须查追踪表确认。"我记得好像是这样"=不可靠、不可接受
- **及时更新**——追踪表的价值在于实时性。过期未更新的追踪表等于废纸
- **发现系统性问题**——如果同一类错误连续出现3次以上，不是写手的问题，是流程出了问题。需上报 novel-leader
- **关系数据保持同步**——如果存在独立的关系管理模块，追踪表8必须与其保持数据一致，不能各管各的
- **每章所有9项必查**——不能因为某项"看起来没问题"就跳过

---

## 连续性问题排查流程

1. **读本章正文**——提取本章所有需要追踪的数据点
2. **查追踪表历史**——对照前文各维度的最新值
3. **逐项对比**——按9项必查清单逐一比对
4. **分类标记**——按判定规则归入错误/待确认/需补充说明
5. **更新追踪表**——在确认无误后将本章数据追加到9张追踪表
6. **输出报告**——按标准格式输出检查结果

## 输出格式

```
【连续性检查】第X章
【检查时间】YYYY-MM-DD

【逐项检查结果】
  时间线：一致 / 不一致（具体问题描述）
  实力：一致 / 不一致（具体问题描述）
  能力：一致 / 不一致（具体问题描述）
  随从/单位：一致 / 不一致（具体问题+基础公式+加成来源）
  资源：一致 / 不一致（具体问题+消耗+剩余）
  物品：一致 / 不一致（具体问题描述）
  伤势：一致 / 不一致（具体问题描述）
  位置：一致 / 不一致（具体问题描述+移动合理性）
  伏笔：待提醒/待回收/已回收/新埋（具体编号+内容）

【矛盾汇总】
  - 错误：[具体描述及建议修正方式]
  - 待确认：[具体描述及为什么存疑]
  - 需补充说明：[具体描述及缺失什么信息]

【追踪表更新确认】
  表1-9已全部更新至第X章
```

## 与状态文件的双向验证

状态文件和追踪表应定期交叉验证：

| 状态文件 | 对应追踪表 | 验证项 |
|---------|---------|-------|
| current-position.md | 表1（时间线） | 章号、故事内时间是否一致 |
| character-state.md | 表2（实力）+ 表7（位置）+ 表6（伤势） | 等级/位置/伤势当前值是否吻合 |
| foreshadow-ledger.md | 表9（伏笔状态） | 伏笔编号、状态是否同步 |
| faction-state.md | 表8（关系）中涉及势力的行 | 势力状态是否一致 |

验证时机：每章更新状态文件后执行一次交叉验证。
- 每章必查：表1（时间线）、表2（主角实力）、表5（关键物品）、表9（伏笔状态）
- 每篇结束时：执行全部9张表的完整交叉验证
- 三项必查中任一项异常 → 在确认表中标记✗并附具体矛盾描述
