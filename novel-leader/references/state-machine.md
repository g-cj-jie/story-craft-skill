# 写作阶段状态机

## 状态定义

| 状态 | 说明 | 触发转换的条件 |
|------|------|---------------|
| INIT | 初始化：理解题材，确认写作方向 | 用户确认题材方向 → PREP |
| PREP | 资料准备：世界观搭建/原作采集/改编方案 | 资料准备完成，用户确认 → DESIGN |
| DESIGN | 故事设计：部纲→卷纲→篇纲→章纲，追踪表 | 篇纲就绪，用户说"开始写" → WRITING |
| WRITING | 写作循环：写→审→改→过→存→下一章 | 部内所有篇章完成 → REVIEW_PART |
| REVIEW_PART | 部完成，等候用户审查 | 用户确认 → DESIGN(下一部) 或 WRITING(继续) |
| COMPLETE | 全书完结 | — |

## 暂停条件

以下任一情况必须立即暂停自动循环：
- novel-review 连续3次未通过同一章
- 用户明确说"停"
- 到达部边界
- state/ 文件出现明显矛盾（同一人物两个不同状态）
- 伏笔台账出现超期未填（超过预定范围3篇以上）
- 上下文Token预估超过8000

## 新会话恢复

当在新对话中启动时（无历史上下文）：
1. 检查 `state/current-position.md` 存在性
2. 若存在：读取 state/ 下所有文件 + 当前篇纲，报告当前进度
3. 若不存在：提示用户确认项目目录，从 INIT 开始
